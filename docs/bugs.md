Project Bug Report
Document Title: Project Testing – Identified Bugs and UI Issues
Testing Type: Manual Testing
Focus: UI, Responsiveness, Date Picker, Theme Compatibility and Booking Functionality
1. Summary
During manual testing of the project, I identified five bugs related to mobile responsiveness, booking functionality, image visibility, and dark/light mode compatibility.

These issues affect the user experience and the overall appearance and functionality of the application. The following bugs need to be fixed to ensure smooth operation across different devices and screen sizes.
2. Detailed Bug List
Bug 1: Incorrect Date Format on Mobile Devices
- Description: The date format is not displayed correctly on mobile devices.
- Expected Result: Dates should appear in a consistent and readable format across all devices.
- Actual Result: The date format appears incorrectly or inconsistently on mobile screens.
- Impact: Users may face difficulty understanding booking dates.
Bug 2: Dark Mode and Light Mode Issue in Booking Agreement Letter
- Description: The booking agreement letter does not display properly when switching between dark mode and light mode.
- Expected Result: The agreement letter should be clearly visible and readable in both themes.
- Actual Result: Text and background colors do not adjust properly when changing themes.
- Impact: Users may experience difficulty reading the booking agreement.
Bug 3: Calendar Not Visible During Return Date Selection
- Description: When attempting to make a booking, the calendar does not appear while selecting the return date.
- Expected Result: The date picker calendar should open properly when the user selects the return date.
- Actual Result: The calendar is not displayed during return date selection.
- Impact: Users may be unable to select their desired return date and complete the booking process.
Bug 4: Images Not Displaying on Some Devices
- Description: Images are not visible on certain devices.
- Expected Result: All images should load and display correctly across different devices.
- Actual Result: Some images fail to appear on certain devices.
- Impact: This affects the visual experience and may prevent users from viewing important information.
Bug 5: Text Not Visible in Dark Mode on the Front Page
- Description: The text "Simple steps. Clear agreements." on the homepage is not visible in dark mode.
- Expected Result: The text should remain clearly visible in both dark mode and light mode.
- Actual Result: The text does not appear properly when dark mode is enabled.
- Impact: Users cannot properly read the homepage content in dark mode.
3. Overall Bug Summary
Bug No.	Identified Issue	Priority
1	Incorrect date format on mobile	Medium
2	Agreement letter theme issue	Medium
3	Return date calendar not visible	High
4	Images not displaying on some devices	High
5	Homepage text invisible in dark mode	Medium

4. Conclusion
During manual testing, five issues were identified in the application. Most of these bugs are related to user interface consistency, theme compatibility, and booking functionality.

The development team should prioritize fixing the return date calendar and image visibility issues, followed by the remaining UI and theme-related issues.

Fixing these bugs will improve application usability, responsiveness, accessibility, and the overall user experience.
